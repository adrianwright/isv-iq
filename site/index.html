Proof of concept / synthetic data only

One renewal question. Four Microsoft IQ layers. Human review stays in control.

ISV IQ shows how a software company can combine structured account data, contract and policy documents, account-team context in Microsoft 365, and current public evidence into one cited assessment of a customer renewal. It recommends a forecast decision and drafts the next action. Nothing is sent automatically.

The scenario

A renewal-forecast question that crosses data boundaries.

"Should we increase the Alder Creek Unified School District renewal forecast from $2.2M to the full $2.4M ARR?"

A useful answer needs more than a CRM record. It reconciles usage and support data, contract and approval policy, what the account team has promised, and what is changing at the customer, and it surfaces uncertainty instead of hiding it.

Why it matters

The answer lives in four different places.

No single system holds everything the account team needs, and none of it is in the CRM opportunity record.

Structured account data

Microsoft 365 context

How it works

Parallel retrieval. Explicit uncertainty. Human review.

  1. 01
    Interpret the question

    Resolve the account, renewal, requested decision, and missing facts.

  2. 02
    Retrieve in parallel

    Dispatch Foundry, Fabric, Work, and Web context requests concurrently.

  3. 03
    Reconcile the evidence

    Separate criteria met from blockers, contradictions, and missing evidence.

  4. 04
    Draft a governed next action

    Return citations, an owner, and a task that stays drafted and unsubmitted.

Evidence you can inspect

01 / Trace

Every IQ layer shows its work.

An activity panel shows each IQ layer running in parallel, the source data flowing in, how long each took, and how many citations it contributed. Findings link back to the evidence behind them.

  • Per-layer status, latency, and citation counts
  • Source-level evidence for every material finding
  • Contradictions and missing evidence called out

02 / Govern

The output ends in review, not automation.

The assessment returns a Yes, No, or Not yet verdict with confidence, makes open issues prominent, and assigns a next action without sending a message or changing a customer system.

Honest about the proof-of-concept boundary

01

Connected architecture

Live Foundry, Fabric, Work, and Web integrations run on Azure, with Microsoft Fabric holding the structured data and Microsoft 365 holding the team context.

02

Deterministic local fallback

The full walkthrough also runs against deterministic synthetic data without an Azure account or live service access, so demos stay reproducible.

03

Human review, fictional data

Tasks stay drafted, not submitted. The districts, contracts, people, and figures are fictional, and the output is not a commitment or a forecast of record.
